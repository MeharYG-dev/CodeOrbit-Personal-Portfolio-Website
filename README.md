
# CodeOrbit Personal Portfolio Website

A responsive personal portfolio website developed as part of the CodeOrbit internship program. The website introduces my profile, showcases my skills and projects, and provides a way for visitors to learn more about my work.

## 🚀 Features

- Responsive design for desktop, tablet, and mobile devices
- Personal introduction and profile section
- Skills and technologies section
- Projects showcase
- Contact section for professional communication
- Clean and user-friendly layout

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript

## 📁 Project Structure

```text
CodeOrbit-Personal-Portfolio-Website/
├── index.html
├── style.css
├── script.js
└── README.md
```

## ⚙️ How to Run the Project

1. Clone the repository:

   ```bash
   git clone https://github.com/MeharYG-dev/CodeOrbit-Personal-Portfolio-Website.git
   ```

2. Open the project folder.
3. Open `index.html` in your browser.

You can also open the project in Visual Studio Code and use the Live Server extension.
